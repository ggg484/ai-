能开火 / 爆头击杀 / 击杀金钱 / 下包 / 引爆结算 / 进入第 2 回合 / 回合重置 /

实现要点（改的时候别踩）：

- 零依赖：用 Node 22 内置 `fetch` + `WebSocket` 直连 CDP，不引 playwright
- Linux 上自动套 `xvfb-run` 重跑自己（容器里 `DISPLAY=:0` 常常是假的，不能靠它判断）
- **必须复用启动时那个 page target**，不要 `PUT /json/new` 新建 tab：
  后台 tab 的 `requestAnimationFrame` 会被节流，主循环几乎不跑
- **不要靠 `setTimeout` 等游戏推进**：软件渲染只有 3–5 fps，会随机失败。
  统一用 `for (let i=0;i<n;i++) g.simulate(1/64)` 手动推进，确定性且快

### P0-3 真机触屏验证

**为什么**：触屏操作只在桌面模拟器里试过，真机的触摸延迟、摇杆死区、
按钮大小全是未知数。这是**唯一必须在真机上做**的事。

| 项 | 内容 |
|---|---|
| 文件 | `index.html`（触屏层）、`css/game.css`、`js/core/input.js` |
| 函数 | `_bindTouch()`、`_moveStick()` |
| 工期 | 0.5 天 |
| 依赖 | 一台真手机 |

要验的：

- [ ] 左摇杆推到底，走速是否够快（应 ≈ 5 m/s）
- [ ] 推半程是否明显变慢（`maxSpeed *= |axis|`，半程 ≈ 2.5 m/s）
- [ ] 摇杆死区：手指轻放时是否抖动
- [ ] 右侧拖动视角，灵敏度是否合适（当前 0.0034 rad/px）
- [ ] 开火按钮按住是否连发（AK 全自动）
- [ ] **蹲下必须是切换式**（按一下蹲、再按一下站），当前代码是按住式，**这条要改**
      理由见 `PRINCIPLES.md` §1.3：按住蹲会占掉一根手指，玩家没法同时移动+开火
- [ ] 按钮是否被刘海/圆角挡住（切刘海验证 `--safe-*`）
- [ ] 同时按「移动 + 开火 + 转视角」是否掉触点（多点触控）
- [ ] 连续操作 20 次（走位+开火+换弹）无误触
- [ ] **大厅 420+ 人同屏 + 战斗场景，中端真机稳定 ≥ 60 fps（p95 帧时间 ≤ 16.7 ms）**
      用 `?perf=1` 或 F3 看探针；`?noadapt=1` 锁 medium 做固定档压测

**已知问题**：`Input` 的 `stick` 只支持单指，`lookId` 也只支持单指。
如果真机上出现「按开火时视角不能转」，说明按钮的 `pointerdown` 吃掉了 touch，
需要给按钮加 `touch-action: none` 并检查 `pointerleave` 的触发时机。

- 第 12 回合结束（打完 12 回合）交换攻守
- 12:12 进加时，加时 6 回合（3+3），先到 4 胜，起始金钱 10000

现在 `Round` 只有 `round` 计数器，没有「上半场/下半场」概念。
最小改法：加 `this.half = 1` 和 `this.side = 'T'`，在 `end()` 里判断 `round === 12` 时交换。

**攻守交换要同时改**：玩家出生点、Bot 出生点、包点归属、购买区。
建议把「谁是 T」抽成一个 `this.attackers` 字段，所有判断读它。

### P1-5 Bot 视野与听觉

| 项 | 内容 |
|---|---|
| 文件 | `js/game/bots.js` |
| 函数 | `update()` 的 `patrol` / `engage` 分支 |
| 工期 | 3 天 |
| 依赖 | 无 |

现在 Bot 是「全知」的——只要在 8–20 m 内就会交战。要加：

- **视野锥**：夹角 100°，距离 40 m，用 `world.lineOfSight()` 确认没被墙挡
- **听觉**：玩家开枪（半径 35 m）、跑步（半径 12 m）、静步（半径 4 m）会让附近 Bot 转向
- **记忆**：看不见玩家后追到最后已知位置，3 秒没找到就回巡逻
- **找掩体**：交战时如果血量 < 40，退到最近的掩体后面

**验收**：玩家蹲在掩体后静步移动，Bot 不应该发现；
玩家在 30 m 外开枪，Bot 应该朝枪声方向转。

### P1-7 音效资产

| 项 | 内容 |
|---|---|
| 文件 | `assets/sfx/*.ogg`（新建）、`js/core/audio.js` |
| 工期 | 2 天（含找素材） |
| 依赖 | 无 |

现在全部是 WebAudio 合成音（`audio.js` 里的 `synth()`）。合成音的问题是
「能听出是枪声，但没有质感」。

需要的 12 个文件（`audio.js` 里已经用到这些名字）：

```
shot_rifle.ogg   shot_pistol.ogg  hit.ogg      headshot.ogg
reload.ogg       empty.ogg        step.ogg     beep.ogg
plant.ogg        explode.ogg      win.ogg      lose.ogg
```

规格：单声道 OGG Vorbis，44.1 kHz，单文件 ≤ 80 KB，峰值 -3 dBFS。
枪声要留 200 ms 尾巴（房间混响），脚步声要短（< 150 ms）。

**平台限制**：`Builda.audio.playSFX()` **不支持声像（pan）**。
想要「听声辨位」得自己做 WebAudio 混音，或者接受听不出方向。

## 明确不做的事（避免浪费时间）
