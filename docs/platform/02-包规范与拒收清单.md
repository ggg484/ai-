# 包规范与拒收清单

> 这一页是「上传失败时先查哪里」。规则来源：`bundle-check` 的实际校验项 +
> `docs/官方主题/md_agent_publish.md` / `md_agent_html5.md` / `md_agent_godot.md` / `md_agent_unity.md`。

## 1. zip 里面应该长什么样

**H5（本包示例）**

```
builda-web.zip
├── index.html          ← 必须在根
├── game.js
└── assets/…            ← 游戏自己的静态资源（可选）
```

**Godot Web**

```
index.html  index.js  index.wasm  index.pck
```

**Unity WebGL**

```
index.html
Build/…                 ← 四个文件（*.loader.js / *.framework.js / *.wasm / *.data，可为 .unityweb）
TemplateData/…
StreamingAssets/…       ← 可选
```

三种引擎都一样：**zip 根就是入口 `index.html`，不能多套一层目录**（`builda-web/`、`dist/` 这种都不行）。

## 2. 必须满足

| 项 | 说明 |
|---|---|
| 根 `index.html` | 入口文件，`buildEntry` 默认就是它 |
| SDK 引用 | `<head>` 里有根相对引用 `<script src="builda-sdk.js"></script>`；**SDK 文件本身不打进 zip**，线上由 App 注入 |
| 离线自包含 | 所有 JS/CSS/图片/音频都在包里，不允许运行时拉外部 CDN |
| `Builda.runtime.ready()` | 入口脚本第一件事就调用；30 秒内宿主没收到会直接关游戏 |
| 文件名分隔符 | 必须是 `/`；不能有绝对路径、盘符、`..` |
| 编码 | 标准 UTF-8；不要带 BOM 的异常路径名 |

## 3. 禁止出现在 zip 里的东西

| 类别 | 具体文件 |
|---|---|
| 依赖/源码 | `node_modules/`、`src/` 源码目录、`.env`、`*.map`（sourcemap）、`*.d.ts` |
| 版本控制/编辑器 | `.git/`、`.github/`、`.vscode/`、`.idea/`、`.DS_Store` |
| Godot 工程 | `project.godot`、`export_presets.cfg`、`.godot/`、`*.import` |
| Unity 工程 | `Assets/`、`Library/`、`Temp/`、`Obj/`、`ProjectSettings/`、`*.meta`、`*.csproj`、`*.sln`、`*.unity` |
| 预压缩裸文件 | `*.br`、`*.gz`（Unity 开了压缩却没勾 Decompression Fallback 时会产出，**直接拒收**） |
| 包内 SDK | `builda-sdk.js` 本体（引用可以，文件不要打进去） |

> 规则不是洁癖：`bundle-check` 会逐条硬校验，命中就不让传。

## 4. 体积与配额

| 项 | 限制 |
|---|---|
| 主包 zip | 默认 **200 MiB**；首个版本（还没有 gameId）同样 200 MiB |
| 老游戏放宽 | 当前账号名下的老游戏，服务端白名单可放到 **201–500 MiB**；编译期硬顶 500 MiB |
| 50 MiB 提示 | 超过会打印 `bundle-size-hint`，**只是建议拆资源，不阻断** |
| 资源包 assets.zip | 压缩默认 340 MiB（可放宽 500），解压 ≤1024 MiB，单文件 ≤32 MiB，≤10000 文件 |
| wasm | 单个 `.wasm` ≤1 GiB（Godot / Unity 的 WASM 内存也同样 ≤1 GiB） |

拆包优先级：3D 模型/大图/关卡 → `res/**`；长音频 → `assets.zip` 的 `audio/**`；字体做子集化；纹理压缩；Unity 开 Strip Engine Code。

## 5. 兼容性扫描（会被草稿提交拦住）

`upload-build` 会顺着 `index.html` 扫描实际加载的 JS，打印：

```
bundle-compat-required-chrome=88
bundle-compat-finding=game.js:12:5 …
bundle-compat-fix-item=…
```

`create-draft` / `update-draft` 会拒绝 `minChromeMajor` 低于该值的草稿。

常见原因与修法：

| 写法 | 最低 Chrome | 修法 |
|---|---|---|
| `??=` `||=` `&&=` | 85 | 打包目标设 `es2020` |
| 私有方法 `#x()` | 84 | 同上 / 改普通方法 |
| 顶层 `await` | 89 | 包进 async 函数 |
| `class { static {} }` | 94 | 改静态初始化块 |
| `replaceChildren` | 86 | 加 polyfill 或改 `innerHTML=''` + append |
| `structuredClone` | 98 | 用 JSON 深拷贝或 polyfill |
| `crypto.randomUUID` | 92 | 自写 UUID |
| Canvas `roundRect` | 99 | 自绘圆角矩形 |
| WebAssembly 异常处理 | 95 | 引擎决定，只能提高 `minChromeMajor` |

修代码优先，不要靠抬高 `minChromeMajor` 蒙混——每个版本门槛都会挡掉一批玩家（Chrome 81 覆盖约 98.5%，85 约 89.5%，88 约 88%）。

## 6. 最常见的 10 种拒收

| 现象 | 原因 | 处理 |
|---|---|---|
| `index.html not found at zip root` | 多套了一层目录 | 进到构建目录内部再 zip |
| `index.html does not load builda-sdk.js` | 漏了 `<head>` 引用 / 被构建工具内联 | 保持根相对 `<script src="builda-sdk.js">` |
| `File types not allowed: .map` | 开了 sourcemap | 关掉重新构建 |
| 含 `node_modules/` | 直接压了工程根 | 只压构建产物 |
| `backslash path` | Windows `Compress-Archive` | 用 7-Zip 或 WSL `zip` |
| Unity `.br/.gz` 被拒 | 压缩开了但没勾 Fallback | 改 Brotli + Decompression Fallback，或 Disabled |
| Godot 启动黑屏 | 多线程导出 + WebView 不支持 SharedArrayBuffer | 用单线程导出（`thread_support=false`） |
| 包太大 | 素材没拆 | 按第 4 节拆 `res/**` / `audio/**` |
| 草稿提交被拒：`minChromeMajor too low` | 代码用了新语法 | 按第 5 节修，或如实提高版本 |
| 上传 409 | 有未结束的会话 | `upload-list` 查，确认废弃再 `upload-cancel` |

## 7. 自检脚本（本包附带）

```bash
cd game
npm run pack                                   # 生成 dist/ 与 builda-web.zip
./.builda-agent/builda bundle-check --engine h5 builda-web.zip
unzip -l builda-web.zip | head                 # 肉眼确认根目录结构
```
