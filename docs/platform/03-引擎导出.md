# 引擎导出：Godot / Unity / HTML5（含 Cocos）

> 平台只收 **Web 产物**（静态站点 zip），不收 APK/IPA/EXE，也不收 UE。
> 三种引擎的 `engine` 值分别是 `godot` / `unity` / `h5`，`builda engine detect` 会自动识别。
> 官方原文：`docs/官方主题/md_agent_godot.md`、`md_agent_unity.md`、`md_agent_html5.md`。

## 0. 一张表看懂差别

| | Godot Web | Unity WebGL | HTML5 / Cocos |
|---|---|---|---|
| 引擎版本 | Godot 4.x（3.x 也能查模板） | Unity 2021.3 LTS+ | 任意 Web 构建 |
| 必装模块 | Web 导出模板 | WebGL Build Support | — |
| 关键开关 | 单线程导出 | 压缩 + Decompression Fallback | 关 sourcemap |
| WASM 内存 | ≤1 GiB | ≤1 GiB | 单个 wasm ≤1 GiB |
| 入口产物 | `index.html` + `index.js/wasm/pck` | `index.html` + `Build/` 四件 | `index.html` + 你的 JS/CSS |
| 中文字体 | 建议子集化 | **必须**嵌字体（WebGL 无系统字体回退） | 系统字体即可 |
| 本地调试 | `builda dev --web build/web` | `builda dev --web Builds/WebGL` | `builda dev --web dist` |

## 1. Godot Web

### 1.1 前置检查

```bash
# 工程根要有 project.godot
./.builda-agent/builda godot web-template-check godot4
```

报缺模板，通常是 `$HOME/.local/share/godot/export_templates/<version>/web_release.zip` 不存在；
装同版本 Web 导出模板，或把另一台机器同版本目录整体拷过来。

### 1.2 导出设置（单线程）

Web preset 里固定：

```ini
variant/thread_support=false
variant/extensions_support=false
progressive_web_app/ensure_cross_origin_isolation_headers=false
progressive_web_app/offline_page=""
```

移动端 WebView 默认不支持 SharedArrayBuffer；开多线程会黑屏或卡在加载。
只有明确只发 iOS 且用户要求时才考虑多线程变体。

### 1.3 导出与打包

```bash
mkdir -p build/web
godot4 --headless --path . --export-release "Web" build/web/index.html
(cd build/web && rm -f ../builda-web.zip && zip -r ../builda-web.zip .)
./.builda-agent/builda bundle-check --webview-compatible build/builda-web.zip
```

- 导出目录里**不要**手动拷 `builda-sdk.js`，zip 不打包 SDK
- 不要把 `project.godot`、`export_presets.cfg`、`.godot/`、`*.import` 压进去
- 内存设置超过 1 GiB 要先降下来

## 2. Unity WebGL

### 2.1 环境

- Unity **2021.3 LTS 或更新**，安装 **WebGL Build Support**
- 执行过 `builda sdk install`，`Assets/WebGLTemplates/Builda/` 已就位
- Player Settings → Resolution and Presentation → **WebGL Template 选 `Builda`**
  （模板 `<head>` 里已经带 `builda-sdk.js` 引用，这是上传硬校验项）

### 2.2 压缩（最容易整包被拒）

`Player Settings → Publishing Settings → Compression Format` 只能二选一：

| 选项 | 产物 | 说明 |
|---|---|---|
| **Brotli/Gzip + Decompression Fallback 勾上**（推荐） | `Build/*.unityweb` | 自带 JS 解压器，任意静态服务器都能跑 |
| **Disabled** | 裸 `*.wasm` / `*.data` / `*.framework.js` | 启动快、体积大 |
| 压缩开了但 Fallback 没勾 | `*.wasm.br` / `*.data.gz` | **硬拒收**，`.br/.gz` 不在白名单 |

### 2.3 内存与字体

- WASM 内存 ≤ **1 GiB**（超了移动端 WebView 大概率起不来）
- WebGL 下 TMP / Legacy Font **都没有系统字体回退**，中文必须嵌子集字体；
  排行榜这类开放文本还要做缺字过滤（细则见 `.builda-agent/sdk-guidance/0.26.6/md_unity_webgl.md` 第 5 章）

### 2.4 构建与打包

```bash
# File → Build Settings → WebGL → Build，输出到 Builds/WebGL
(cd Builds/WebGL && rm -f ../../builda-web.zip && zip -r ../../builda-web.zip .)
./.builda-agent/builda bundle-check builda-web.zip
```

产物结构：根 `index.html` + `Build/` 四件 + `TemplateData/` +（可选）`StreamingAssets/`。
`Build/` 目录名不要改。

## 3. HTML5（含 Cocos Creator）

### 3.1 通用流程

```bash
npm run build                  # 产出 dist/ 或 build/
(cd dist && rm -f ../builda-web.zip && zip -r ../builda-web.zip .)
./.builda-agent/builda bundle-check --engine h5 builda-web.zip
```

要求：

- 根 `index.html`，`<head>` 保留 `<script src="builda-sdk.js"></script>`
- 全量自包含，不引外部 CDN
- 关 sourcemap；不要带 `node_modules/`、`.d.ts`、`.env`
- 字体优先系统字体（`font-family: system-ui, "PingFang SC", "Microsoft YaHei", sans-serif`），
  品牌字体再子集化打包
- 自带 wasm/worker 可以，单个 wasm ≤1 GiB

### 3.2 Cocos Creator

按 **HTML5（engine=h5）** 走，构建平台选 **web-mobile**，上传构建输出目录。

SDK 引用用自定义构建模板，避免每次构建丢引用：
在工程根建 `build-templates/web-mobile/index.html`（从一次构建产物里拷出来改），
在 `<head>` 加 `<script src="builda-sdk.js"></script>`，之后每次构建自动带上。

构建配置约束：

| 字段 | 要求 | 原因 |
|---|---|---|
| `mainBundleIsRemote` | **必须 `false`** | 远程 bundle 在 CDN 环境直接起不来 |
| `sourceMaps` | **必须 `false`** | `.map` 会被拒，且泄露源码 |
| `packages.<platform>.orientation` | 与 `builda.publish.json` 的 `orientation` 一致 | 否则容器与画布方向冲突 |
| `debug` | 建议 `false` | 体积与性能 |
| `md5Cache` | 可 `true` | 只改 Cocos 自己资源名，不影响根路径 SDK 引用 |

### 3.3 其他 H5 框架

PixiJS / Phaser / Laya / 原生 canvas / 自编译引擎（Emscripten、TeaVM）都归 `h5`，
只要产物满足上面的结构要求即可。

## 4. 导出后共同动作

```bash
# 1) 本地跑（会自动映射 mock SDK 与 assets/）
./.builda-agent/builda dev --web <构建目录>

# 2) 看输出里的 dev-url，在浏览器里真玩一遍：
#    切横竖屏、切刘海、切 mock 玩家、点一次支付/广告看成功与失败分支

# 3) 打包 + 校验
./.builda-agent/builda bundle-check <zip>

# 4) 同步草稿
./.builda-agent/builda publish <zip>
```
