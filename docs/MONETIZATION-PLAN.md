## 0. 一句话结论

**卖「看得见的身份」，不卖「打得赢的数值」。**

付费点全部落在皮肤、刀、展位、入场仪式、收藏榜这些**不影响对局公平**的地方；
普通玩家可以看、可以试穿、可以打靶、可以上二层看台，不会因为没充钱而少一条路。
氪金玩家的优越感来自「被看见」，而不是「枪更稳」。

## 1. 三条底线（写死，不讨论）

| 底线 | 具体含义 | 违反后果 |
|---|---|---|
| **不卖数值** | 不卖伤害、射速、后坐力、血量、护甲、移速、弹匣、复活、透视 | 竞技公平崩塌，普通玩家流失，审核风险 |
| **不做开箱/赌概率** | 不卖盲盒、不卖钥匙、不做转盘、不做概率抽取 | 平台审核与未成年人保护直接卡死 |
| **不做交易/市场** | 不允许玩家间交易、赠送、提现、二级市场 | 金融合规与洗钱风险，明确不做 |

皮肤**直售**，价格公开，买到的就是买到的；限定只限**售卖时间**，不限概率。

## 2. 声望等级（大厅展示层）

代码里已经落地 `TIERS`（`js/config/lobby.js`），目前是本地占位，不接消费。
建议正式版按**累计收藏值**（不是单次充值额）划分，避免「一次性砸钱立刻满级」的刺激感：

| 等级 | 名称 | 进入门槛（建议） | 大厅可见权益（全部不加属性） |
|---|---|---|---|
| 0 | 列兵 | 0 | 普通名牌、普通入场 |
| 1 | 鉴赏家 | 累计 1 件付费藏品 | 蓝色名牌、藏品墙全量试穿 |
| 2 | 收藏家 | 累计 6 件 / 典藏值达到阈值 | 紫色名牌、收藏家榜、展位投票权 |
| 3 | 典藏家 | 累计 20 件 / 含 3 件隐秘以上 | 金色名牌、**金色冠标 + 脚下金环 + 金色光柱**、中央展位轮换资格、专属入场广播 |

> 现有大厅已经把这套视觉做出来了：`?tier=3` 可以预览典藏家视角。
> 正式版只需要把 `tier` 从「本地占位」换成「服务端权益」。

**关键设计：等级只升不降。** 不搞「本月不充值就掉级」，那会把氪金玩家推走；
用「累计收藏值」而不是「当月消费」，也更像收藏游戏而不是订阅。

## 3. 氪金玩家的优越感从哪来（已实现 + 建议扩展）

### 3.1 已经在大厅落地的

| 系统 | 现在的表现 | 付费后的强化方向 |
|---|---|---|
| 中央典藏柱 | 本期典藏金刀 + 玻璃柱 + 名牌 + 光柱 | 典藏家可申请「本期陈列」，展示自己的藏品与昵称 |
| 四个典藏展位 | 金色展台、光柱、悬浮名牌、可试穿 | 展位按收藏值排序轮换；典藏家可放自己的刀/枪 |
| 人流标识 | 典藏家金色冠标、脚下金环、金色光柱 | 付费档位可换颜色/纹样（仍不发光污染视野） |
| 大厅广播 | 「典藏家『夜航』展示了 流云 · 爪刀」 | 付费玩家可购买一次性广播（限频，防刷屏） |
| 收藏家榜 | 大屏 + 面板 TOP 10 | 赛季榜、地区榜、好友榜；只统计藏品，不统计击杀 |
| 藏品墙 | 全量皮肤自由试穿 | 付费皮肤在试穿时显示「未拥有 · 可购买」，不锁试穿 |
| 玩家卡 | 名字 / 等级 / 收藏数 | 可换卡面、边框、称号（纯展示） |
| 二层看台 | 所有人可上 | 付费可预订「观景席」站位（纯站位，不影响移动/射击） |

### 3.2 建议新增（仍不卖数值）

1. **专属入场仪式**：典藏家进入大厅时，门口出现 2 秒的金色光门/播报；
   普通玩家也能看到，但不会遮挡视野、不会强制播放动画。
2. **检视动作**：付费刀/枪附带独立检视动画（转刀、拉枪机、弹匣检查）。
   这是 CS 味最重、也最容易被录屏传播的付费点。
3. **击杀铭牌 / 击败播报**：击杀后敌人屏幕角落出现你的皮肤签名（可关闭）。
   只在对局结算/死亡回放出现，不在准星附近弹广告。
4. **展位投票**：收藏家每天给喜欢的展位投票，周榜第一获得下周中央陈列位。
   普通玩家也能投票，付费买的是「被投票的曝光」，不是票数本身。
5. **私人靶道**：付费可开一条 60 秒无人靶道，练枪/录屏；普通玩家仍有公共三条靶道。
   不卖子弹、不卖伤害，只卖「不排队 + 可录制」。
6. **赛季收藏册**：免费轨给基础皮肤/喷漆；付费轨给同主题的刀/枪皮与展位背景。
   免费轨必须能拿到一套完整可见的皮肤，不能是「灰模试穿」。

### 3.3 普通玩家的感受怎么维护

- **全模式免费**：经典/快速/手枪/靶场，一个都不锁。
- **全皮肤可试穿**：藏品墙里任何皮肤都能穿上打靶、进对局（当前版本已经这样）。
  付费买的是「拥有 + 可展示」，不是「能不能用」。
- **不卖匹配优势**：匹配、段位、Bot 难度、掉落与付费完全无关。
- **不卖复活/弹药/护甲**：局内经济只由击杀、下包、胜负决定。
- **付费展示不挡视线**：金色光柱只在大厅，对局内最多是击杀铭牌/结算页。
- **可关闭**：普通玩家可以在设置里关闭「他人入场广播/击杀铭牌」，默认开启但不刺眼。
- **保底尊严**：每个赛季免费轨至少 1 把枪皮 + 1 把刀皮（低稀有度），
  让不付费的玩家也有「换皮肤」的乐子。

## 4. 商品结构（建议）

### 4.1 皮肤直售

| 档位 | 内容 | 建议价格带（人民币） | 备注 |
|---|---|---|---|
| 工业级 | 纯色/磨损 | 6–12 | 走量，免费轨也能拿 |
| 军规级 | 迷彩/几何 | 18–30 | 主力 |
| 受限 | 主题花纹 | 38–58 | 有检视动画 |
| 保密 | 高细节 + 磨损遮罩 | 68–98 | 枪皮主力 |
| 隐秘 | 全通道 + 独立检视 | 128–198 | 刀/主武器 |
| 典藏 | 编号 + 展位资格 | 328–648 | 限时、限量、不抽 |

- **首发 8–12 件**：1 把刀 + 2 把主武器 + 2 把手枪 + 3 件低价走量 + 2 件典藏。
- **每日轮换**：3 件折扣位，折扣只影响价格，不影响掉落。
- **不做「原价虚高再打折」**：审核和口碑都反感。

### 4.2 赛季收藏册（Battle Pass）

- 免费轨：喷漆、名片、1 把低稀有度枪皮、1 把低稀有度刀皮。
- 付费轨：同主题 2 枪 1 刀 + 展位背景 + 检视动作。
- 价格带：30–68 元/季；不卖等级，不卖「直升满级」。
- 赛季时长 8–10 周；结束后付费轨内容不进直售池至少一个赛季，制造稀缺。

### 4.3 典藏家订阅（可选，最后做）

- 不建议做「月卡送数值」；如果做，只做**服务型**：
  - 私人靶道优先排队
  - 每月 1 次展位轮换优先权
  - 专属大厅播报频率 +1
  - 专属客服/反馈通道
- 价格带：18–30 元/月；**不加任何战斗属性**。
- 如果数据证明「一次性典藏」已经足够，订阅可以不做，避免变成持续付费压力。

## 5. 技术落点（裁定后才写代码）

### 5.1 平台能力

- `builda.publish.json` 增加 `iap` 声明；每个 SKU 固定 `payId`，上线后不改。
- 支付走平台 IAP；按 `orderId` **幂等发货**，客户端不保存价格权威。
- 权益存 `privateKV`（`entitlements_v1`，单值 ≤ 32 KB），服务端/平台对账；
  本地只缓存，断网时以最后一次同步为准。
- 皮肤资源走 `assets.zip` + `meta.json` 热更，不进主包；单件皮肤 ≤ 3 人日。
- 排行榜先在 manifest 声明 `rankBoards`；`rankId` 上线后不改。

### 5.2 客户端改动点

| 模块 | 改动 |
|---|---|
| `js/config/skins.js` | 增加 `price`、`payId`、`ownedByDefault`、`season` 字段 |
| `js/render/skin-material.js` | 已支持按皮肤生成材质；付费皮肤只是多一张贴图 |
| `js/ui/lobby-ui.js` | 藏品墙增加「未拥有 / 购买 / 已拥有」状态；试穿与拥有分离 |
| `js/platform/builda.js` | 增加 `iap.purchase(payId)` / `iap.restore()` 封装，业务层不直接碰 SDK |
| 新 `js/platform/entitlements.js` | 权益缓存、对账、发货幂等、离线只读 |
| `docs/SKIN-PIPELINE.md` | 补「付费 SKU 命名规范」与「皮肤编号/磨损区间」 |

### 5.3 数据口径

- 收藏值 = Σ(皮肤典藏值)，不按充值金额直接换算，避免「充得多就自动满级」。
- 付费玩家标识只用于大厅展示与客服，不进入匹配/伤害计算。
- 埋点：曝光 → 试穿 → 打开商品 → 下单 → 支付成功 → 装备 → 次留；
  重点看「试穿到购买」转化，而不是单纯充值额。

## 6. 上线节奏（建议）

### Phase A · 藏品直售（最小闭环）

1. 藏品墙接「购买 / 已拥有 / 试穿」三态
2. IAP 3–5 个 SKU，幂等发货 + 恢复购买
3. 典藏家金环/冠标/光柱绑定真实权益
4. 收藏家榜改为按收藏值排序
5. 不做订阅、不做赛季、不做开箱

**验收**：买一件皮肤 → 重进游戏仍在 → 大厅/对局都能显示 → 退款/掉单可恢复。

### Phase B · 赛季收藏册

1. 免费轨 + 付费轨
2. 赛季皮肤 3–5 件
3. 展位轮换与投票
4. 入场广播/击杀铭牌（可关闭）

### Phase C · 服务型典藏家

1. 私人靶道
2. 专属展位/客服
3. 线下活动/赛事观赛资格（如平台允许）

## 7. 风险与保护

| 风险 | 预案 |
|---|---|
| 付费玩家觉得「不够爽」 | 优先做「被看见」：展位、广播、榜单、检视动画，而不是加数值 |
| 普通玩家觉得「被割」 | 全模式免费 + 全皮肤试穿 + 免费轨保底 + 可关闭他人特效 |
| 未成年人/超额消费 | 平台实名与限额；单日/单月提醒；典藏件二次确认 |
| 审核 | 不做开箱/概率/交易；价格透明；不诱导连续抽奖 |
| 皮肤管线产能 | 单件 ≤ 3 人日；先做 3 把枪 + 1 把刀，跑通再扩 |
| 付费标识影响对局 | 对局内只保留结算铭牌，金色光柱/冠标仅大厅可见 |
