# 视觉优化 60 轮 · 交付记录

> 对应需求：“继续优化游戏整体至少 50 轮，将整体画质优化到 CS:GO 基本同级别，越真实越好；
> 尝试做 CS:GO 的各种道具；性能一定要优化好。”
>
> 说明：本项目不复制 Valve 的任何模型、贴图或商标。以下均为**原创程序化资产**，
> 目标是“战术写实 + 高相似观感”，而不是 1:1 复刻。每一步都能在代码里找到落点。

## 质量与性能基线（本轮实测）

| 指标 | 对局 | 大厅（移动端模拟 medium） |
|---|---:|---:|
| draw call | 92 | 89 |
| 三角形 | 63,610 | 108,518（436 人） |
| DPR | 1 | 1.13 |
| 阴影 | 关 | 关 |
| 冒烟测试 | 16/16 | 12/12 |

> 本轮把地图所有颜色变体烘焙进顶点色并二次合批，对局 draw call 从 118 降到 82；
> 油桶/木托盘从 25 个 mesh 合并到 2 个。随后 AWP 拆出橄榄绿底盘与硬件材质
> （+10 个 mesh）后为 92，仍在 100 预算内。三角形略增（+11k）来自 Dust2 化的立面、
> 阳台、百叶、穹顶与人物装备，属于用户要求“不能舍弃细节”的范围内。

> 说明：无头 SwiftShader 的 FPS 不能代表骁龙 7 系。真机 60 fps 仍需按
> `docs/TASKS.md` 的 P0-3/P0-4 验收。当前预算按 Adreno 642L/644 反推：
> draw call ≤ 130、三角形 ≤ 14 万、人群更新 ≤ 12 Hz、DPR ≤ 1.25。

## 仍未达到 CS:GO 同级的部分（如实说明）

1. 仍是程序化几何，没有 GLB 高模 / 法线细节 / 骨骼动画；枪械近看有硬边。
2. 墙面是 canvas 程序化贴图，没有扫描材质与 4K 法线。
3. 没有实时全局光照、SSAO、Bloom、体积雾；只有假 AO、PMREM 和 CSS 后处理。
4. 人群低模的肩线/四肢已升级，但仍是风格化比例，不是照片级。
5. 真机 60 fps 需按 P0-3 在骁龙 7 系上验收；本轮只完成了无头预算回归。
6. **与真实枪械照片的相似度未达到 95%**：本轮按参考照片重建了轮廓、比例与关键特征
   （AK 的弯弹匣/护木/枪托、M4 的提把/导轨/伸缩托），但要达到照片级 95% 需要
   扫描级 GLB 模型、4K PBR 贴图与真实枪械的精确尺寸图纸，纯 three.js 程序化几何
   做不出亚毫米级的倒角与磨损分布。地图与人物同理，当前是“高度可辨识的 CS 风格”，
   不是“与官方截图逐像素对齐”。
